# Sample data

A tiny set of MATH problems for smoke-testing. The `setup_repo.sh` script
attempts to populate this folder from `../ExpLearn/wasted/glm/data/MATH/` if
it exists on your machine.

If the folder is empty after running `setup_repo.sh`, you can manually
populate it by following the download instructions in `data/README.md`.

**Do not use sample data for evaluation** — accuracy on 5 problems is not
statistically meaningful.
